Execution / P0—P3

先止血，
再合并，最后推广。

Archive 不是安全动作。凭据、部署、版权和数据授权必须先处理；目标仓发布并通过迁移 E2E 后，来源仓才能归档。

P0 / STOP THE BLEED

安全止血

凭据、公开部署、隐私、版权、数据授权。

  • 吊销 Azure / Oracle 等暴露凭据
  • 关闭遗留 Pages 与 Actions
  • 处理小说、商标和题库授权
  • 区分 public source 与 OSS
P1 / ONE SUCCESSOR

合并退役

每组只有一个 successor，不建设迁移平台。

  • Registry 两仓收敛
  • Harness 工作流统一
  • Spellbook / Loom / Guard 归位
  • Remem / Stash / ccstats 单一事实源
P2 / PROVE IT

产品可靠性

所有产品宣称必须由 fresh-install 和 E2E 证明。

  • 主分支 CI 绿色
  • 错误路径 fail closed
  • README 写清真实限制
  • Release 与安装版本一致
P3 / EARN ATTENTION

集中推广

一次只推一个仓库，传播验证过的差异。

  • 十分钟 Quickstart
  • 60 秒无剪辑演示
  • 公开 benchmark / proof
  • 稳定签名 Release
